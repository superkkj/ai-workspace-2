# 첫 버전 확인 계획

이 문서는 실행 계획이다. 실제 결과는 저장소 루트 docs/ai/CHECKS.md와 앱 STATUS.md에 구분해 기록한다.

## 핵심 사용 흐름

- 본인 신발장: 신발 등록→수정→새로고침→같은 값 조회. 다른 사람 신발 조회/수정/참조 금지.
- 질문: 본인 신발을 기준으로 등록→검색/발볼/목적/상태 필터→상세. 질문에 붙는 정보는 명시된 신발 조건이며 비공개 메모는 제외.
- 스냅샷: 등록 뒤 원래 신발을 수정/삭제해도 질문 당시 신발 조건 유지.
- 답변: 로그인 필요, 공백·길이 제한, 본인 답변 삭제, 타인 답변 삭제 금지.
- 선택/후기: 질문자만 기록. 선택 전 후기 불가. 잘못된 날짜·미래 사용일 거절. 같은 질문에 후기가 중복 생성되지 않음. 첫날 후기를 30일 뒤 조회해도 30일 사용 후기로 바뀌지 않고, 작성 당시 기간을 표시. 후기 삭제 후 상태 복귀.
- 삭제: 질문 삭제로 연결된 답변·선택·후기·신고가 정리됨. 신발 삭제는 이미 게시된 질문 삭제와 별개.
- 신고: 실제 대상만 신고 가능. 일반 사용자는 운영 목록/조치를 사용할 수 없음. allowlist 비어 있으면 운영 권한 없음.
- 사용자 경험: 입력 실패 시 내용 유지, 저장중 중복클릭 방지, 오류/로딩/빈상태 구분, 예시 글과 실제 글 분리.
- 화면: 데스크톱과 휴대폰 폭에서 스크롤, 버튼, 폼, 모달, 키보드 닫기와 포커스 확인.

## 검증 한계

owner-private 배포는 소유자에게만 제공하는 시험 버전이다. 실제 서로 다른 계정의 참여·공개 모집·시장 수요·장기 반복 사용을 확인했다고 기록하지 않는다. 로컬 SQLite 기반 HTTP/서비스 검사는 실제 로그인 서비스나 hosted D1 자체의 검증과 구분한다. 브라우저 인증이 없으면 성공한 것처럼 우회하거나 표시하지 않는다.

## 개발 후 7일 사용자 실험안

이미 잘 맞는 운동화가 있고 다음 러닝화를 고민하는 성인 5명에게, 본인 신발 1개 기록과 구체적인 질문 1개를 부탁한다. 협력할 러닝 모임의 운영진 허가가 있어야 모집한다. 실제 연락은 아직 하지 않았다.

기록할 행동은 조건 입력 완료, 유용한 답변과 실제 선택 연결, 선택 뒤 사용 후기를 남기는지다. 구매 주기가 길면 7일 안에는 자료 제공·첫 작업 완료만 확인하고 반복 구매/30일 후기는 실제 기간 후 관찰한다. 가상 예시 조회수를 실제 참여나 수요로 세지 않는다. 최초 5명 중 3명 이상이 기존 신발 조건을 입력하고 실제 선택 질문을 올리는지를 초기 진행 기준으로 제안한다. 수익화·성공률 예측은 하지 않는다.
