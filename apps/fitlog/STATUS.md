## 첫 버전의 검사 기록

- 기존 가이드와 원격 저장소를 읽고 독립 계획/코드 검토를 수행했다. 검토는 별도 ChatGPT 작업자가 수행했으며 Claude 실행으로 기록하지 않는다.
- npm 의존성 설치 완료. 실제 버전을 고정한 lockfile 포함.
- npm run db:generate 성공: 7개 테이블의 schema-only 초기 SQL 생성, 가상 데이터 없음.
- npm test 성공: 실제 생성 SQL/실제 요청 처리기를 SQLite로 실행하는 통합 검사 16개 통과.
- npm run typecheck 성공: 전체 TypeScript 오류 0개.
- Sites build-site.mjs 성공: Worker와 프런트 배포 산출물 생성.
- 작성 첫날 후기가 조회 날짜만 지나서 30일 후기로 변하는 문제를 독립 검토에서 발견해 수정하고 회귀 검사로 확인했다.

## 배포와 브라우저 확인

실제 최신 배포 주소, 브라우저 확인 범위, 원격 커밋 및 자동 검사 상태는 저장소 루트 STATUS.md와 docs/ai/CHECKS.md를 기준으로 확인한다. 운영 DB/실제 로그인/서로 다른 계정 검증은 SQLite 로컬 검사와 구분한다.

기본 공개 범위는 owner-private이며 외부 모집을 시작하지 않았다. FITLOG_MODERATOR_USER_IDS가 비어 있으면 운영 권한이 없으며, 공개 모집 전 운영자 지정과 실제 두 계정의 참여 흐름을 확인해야 한다. 사용자 확보·장기 반복 사용·유료 수요는 아직 미검증이다.
